En kort guide

Så fungerar Claude Code

Claude Code är en AI-assistent som inte bara svarar på frågor, utan som kan göra saker på din dator: läsa filer, skriva kod, köra kommandon och bygga färdiga projekt – tillsammans med dig.

Vad är det?

Vanliga chattbottar ger dig text som du själv får kopiera och använda. Claude Code arbetar i stället direkt i en mapp på din dator. Du beskriver vad du vill ha med vanliga ord, och Claude tar fram en plan, utför stegen och visar vad som hänt. Den här hemsidan är till exempel byggd och publicerad med hjälp av Claude Code.

Hur ett uppdrag går till

  1. Du beskriver måletTill exempel: ”Gör en enkel hemsida om hur Claude Code fungerar.”
  2. Claude tittar runtDen läser filerna i mappen och kollar vilka verktyg som finns installerade.
  3. Claude gör en planUppgiften delas upp i steg som du kan följa medan arbetet pågår.
  4. Claude utför stegenDen skapar och ändrar filer och kör kommandon. Allt som kan påverka något utanför datorn frågar den om först.
  5. Du granskar och justerarDu säger vad som ska ändras, och Claude fortsätter därifrån.

Vad Claude Code kan göra

Läsa och skriva filer

Skapa nya dokument, hemsidor och program, eller ändra befintliga.

Köra kommandon

Installera verktyg, köra tester och starta program i terminalen.

Förklara

Gå igenom kod eller tekniska begrepp på ett begripligt sätt.

Jobba med Git och GitHub

Spara versioner av ditt arbete och publicera det på nätet.

Du har kontrollen

Claude Code ber om lov innan den gör något som är svårt att ångra eller som syns utåt, till exempel att publicera något eller radera filer. Du kan godkänna, neka eller be om ändringar när som helst.

Kom igång

Claude Code finns som app för Mac och Windows, i webbläsaren och i terminalen. I terminalen startar du det så här:

claude

Läs mer i den officiella dokumentationen: docs.claude.com.

Tips för bättre resultat

  • Beskriv vad du vill uppnå, inte bara hur.
  • Börja litet och bygg vidare steg för steg.
  • Säg till om något blev fel – Claude rättar och lär sig av sammanhanget.
